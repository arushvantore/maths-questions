PART 1 — CONCEPT COURSE, L1 → L12

L1 — Flowcharts

  • What: a diagram of the program: oval = start/end, parallelogram = input/output, rectangle = process, diamond = decision, arrows = flow.
  • Exam form: "draw a flowchart for…" or "what shape is the decision box?" — answer: diamond for decisions, rectangle for assignments, parallelogram for input/output, oval for terminal.
  • Gotcha: arrows must show a loop going back, and every diamond has exactly two labelled exits (Yes/No or True/False).
  • Tested in: PSP Contest 1 syllabus announcement (Flowchart was question 1 of the syllabus list, 1 Sep).

L2 — Variables, datatypes, typecasting

x = 10            # int

pi = 3.14         # float

name = "Arush"    # str

flag = True       # bool

n = int("42")     # str -> int (typecast)

f = float("3.5")  # str -> float

s = str(99)       # int -> str

type(x)           # <class 'int'>
  • Gotchas: input() ALWAYS returns a string — n = input() then n + 1 crashes (str + int). Integer division //, remainder %. int("3.7") crashes — use float first.
  • Tested in: quizzes "Print function…Python Variable…Type() function" (2 Sep), assignments Swap Two Variables, Find The Square, Integer Type.

L3 — Input and arithmetic operators

a = int(input())

b = int(input())

print(a + b, a - b, a * b, a / b, a // b, a % b, a ** 2)
  • Gotchas: precedence is ** > * / // % > + -. / always float (7/2 = 3.5), // floors. Two inputs on ONE line: l, r = map(int, input().split()).
  • Tested in: Swap Two Variables (60/60), Rectangle Area, Energy Consumption, Celsius to Fahrenheit, Convert Minute to Hour, Compound Interest, Contest-2 "Find the remainder".

L4 — if–else

if condition:

    # runs when True

else:

    # runs when False
  • Gotchas: the : is required; indentation defines the block (4 spaces); == compares, = assigns; condition can be a comparison directly (if n % 2 == 0:).
  • Tested in: Even or Odd Checker, Who is Greater?, Weather Report, AM_PM, Identify Square or Rectangle, Profit or Loss; quiz "Conditional Statements, Python if-else" (9 Sep, you scored 8/8).

L5 — if–elif–else ladder

L7 — Introduction to functions

def average(a, b, c):

    return (a + b + c) / 3



print(average(80, 90, 70))
  • What: def name(params): body — define once, call anywhere after it. return sends a value out; print only shows it.
  • Gotchas: the function does NOTHING until called; return with no value gives None; a function without return cannot be used in an expression.
  • Tested in: Calculate Percentage Using Function, Percentage-1/-2, Average of Three; workbook Units 1–7.

L9 — Logical operators + functions with nested if–else

if a > b and b > c:      # both must be True

if x == 1 or x == 2:     # either True

if not flag:             # flips True/False
  • Gotchas: and/or/not (words — never &&/||); short-circuit: x != 0 and 10/x > 1 never divides by zero when x == 0; precedence: not > and > or.
  • Tested in: Voter Eligibility, Greater or Equal, NST Library, Museum Booking, Greater of Four; Contest-2 Gatekeeper; assignment sets due 5 Oct (logical operators).

L10 — Function with recursive thinking

def factorial(n):

    if n <= 1:        # BASE CASE — without it: infinite recursion / crash

        return 1

    return n * factorial(n - 1)



def sum_to(n):

    if n <= 0:

        return 0

    return n + sum_to(n - 1)
  • What: a function that calls itself with a SMALLER input, until a base case stops it.
  • Gotchas: every recursion needs a base case; each call multiplies stack frames (deep recursion hits the limit); trace with a call tree on paper.
  • Tested in: workbook Unit 12 (Recursion Made Easy), sum_to / sign / factorial patterns in Slack sheets; "Factorial-Loops" and "Is It Prime?" carry Recursion in their topic tags (Part 3 has loop versions — both forms examinable).

L11 — For loop

for i in range(1, n + 1):   # 1..n inclusive

    print(i * i)

for i in range(n):          # 0..n-1

    ...

for ch in "abc":            # iterate a string

    ...
  • Gotchas: range(a, b) stops at b-1; range(n) starts at 0; accumulating needs total = 0 BEFORE the loop (a total = 0 inside prints the last value only); print-on-same-line vs newline: print(x, end=" ").
  • Tested in: Sum 1 to N, Multiplication Table, Print all divisors, Multiples of 3 and 5, Squares I/II, Count Divisible by 3 or 5, Fibonacci, Odd Factors, First Number Divisibly by 7 (Part 3).

L12 — While loop

n = int(input())

while n > 0:

    digit = n % 10      # take last digit

    n //= 10            # drop last digit
  • What: repeats while the condition stays True — use when you don't know how many iterations (digit counting, reversing, searching).
  • Gotchas: you must CHANGE something the condition depends on, or it loops forever; break exits the loop, continue skips to the next check; while True + break is legal.
  • Tested in: Count the Digits, Reverse a Number, Digit Sum, First+Last Digit, Even/Odd digit counts, Largest/Smallest Digit, Armstrong, Palindrome number, All Digits Same, Check if Rare, Perfect Number (all in Part 3); quizzes "While loop" (12 Oct, 0/10), "Control flow, Break, Continue" (16 Oct, 0/8).

PART 6 — 60-SECOND MORNING CARD (screenshot this)

1. : after if/elif/else/for/while/def. 4-space indent.

2. input() is a string → int(input()) unless told otherwise; two values: a, b = map(int, input().split()).

3. Digit loop = one template: while n > 0: d = n % 10; n //= 10 → count/sum/reverse/max/first/odd-even/add-1 all from it.

4. Accumulator starts BEFORE the loop (total = 0 outside).

5. range(1, n+1) is 1..n; range(n) is 0..n-1; range(n, 0, -1) counts down.

6. Print exact strings: Yes/No, True/False, YES/NO — copy from the statement, never invent case.

7. Prime: loop to i*i <= n; 1 is not prime; 0! = 1.

8. Round-half-down: last digit 5 goes DOWN (Newton and Rounding).

9. Function-only questions: write def + return, no input()/print() unless asked.

10. Huge ranges (10^18): never loop them — arithmetic formula (even-sum) or ≤7 candidates (div-by-7).

11. Recursion: base case FIRST, then return … f(n-1).

12. break exits, continue skips — diamond flowchart = decision, parallelogram = input/output.
